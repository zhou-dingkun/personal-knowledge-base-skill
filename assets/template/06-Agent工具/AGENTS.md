# 06-Agent工具 — 工具脚本与环境说明区

> 本指令在 AI 处理本目录内容时自动加载，优先级高于根 AGENTS.md。

## 用途
集中存放 AI 助手可用的**工具脚本、使用说明**，以及**本机环境说明**，供任何 AI 工具查阅。

## 建议文件
| 文件 | 内容 |
|---|---|
| `环境说明.md` | 本机环境清单：语言运行时、图像 / 文档工具、版本控制等（路径 + 可用库） |
| `工具用法.md` | 各工具调用方法：PDF 文本提取、页面渲染、图像 / 格式转换、Office 文档读取等 |
| `脚本/` | 可直接调用的工具脚本 |

## 规则
1. 新增工具时：脚本放 `脚本/`，用法补进 `工具用法.md`，环境变更补进 `环境说明.md`，并在根 `INDEX.md` 登记
2. 脚本升级**不覆盖旧版**：新建版本文件名或注明变更记录
3. 路径写**绝对路径**，便于跨目录直接调用
4. **不在此存放密钥、令牌、凭据**

## 提示
- 常见缺口：PDF 无文字层（扫描件）→ 先渲染成图片再识读；HEIC 等格式 → 先转换
- 任何解析结论都应**沉淀成 `02-资料库` 的索引笔记**，避免重复解析
