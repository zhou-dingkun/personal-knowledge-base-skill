# 05-作业 — 作业区操作规范

> 本指令在 AI 处理本目录内容时自动加载，优先级高于根 AGENTS.md。
> 用途：AI 依据知识库协助完成作业。**核心规则：每个作业一个独立文件夹。**

## 1. 目录规则（硬性）

- **每个作业一个文件夹**，命名：`YYYYMMDD-课程名-作业名`
  - 例：`20260901-高等数学-第一章习题`、`20260905-工程图学-零件测绘作业`
- 一个作业文件夹内固定结构：

  ```
  <作业文件夹>/
  ├── README.md       # 作业元信息（必填，见 §2）
  ├── 题目/           # 原始题目：题目.pdf / 题目.md / 截图
  ├── 解答.md         # AI 完成的解答（必填）
  ├── 过程/           # 草稿、推导、多轮修改（可选）
  └── 附件/           # 数据、图片、代码等（可选）
  ```

- 新作业一律用 `_模板/` 中的模板初始化，**不要自创结构**
- **不要**在 `05-作业/` 根目录直接堆放作业文件

## 2. 作业元信息（README.md）

每份作业的 `README.md` 必须包含（模板见 `_模板/作业README模板.md`）：
- 课程、作业名、布置日期、**截止日期**、当前 `status`、评分 / 反馈
- `status` 取值：`未开始` | `进行中` | `待提交` | `已提交` | `已批改`

## 3. AI 协助作业流程（每次都要走）

1. **读题**：先读该作业文件夹的 `README.md` 与 `题目/`
2. **检索知识库**：在 `03-笔记/`、`02-资料库/` 中找相关笔记与资料；PDF / 图片必要时用 `06-Agent工具/` 中的工具解析
3. **作答**：写入该作业的 `解答.md`（带 frontmatter）
   - **标注来源**：引用知识库时用相对路径链接（如 `../../03-笔记/学业研究/xxx.md`）
   - **不编造**：不确定处标 `> 待确认：…`，不臆造公式 / 数据 / 结论
   - 保留推导与计算过程，便于核查
4. **更新状态**：同步更新 `README.md` 的 `status` 与 `updated`
5. **回灌知识库**：把可复用的知识点提炼成 `03-笔记/` 下的笔记，并与作业互链
6. **登记**：在根 `INDEX.md` 的 `05-作业` 章节登记

## 4. 其他

- Git 规则与隐私红线沿用根 `AGENTS.md` 第 5、6 节
- 作业完成后**不要删除**，作为记录保留；确需归档时把 `status` 更新为 `已批改`
