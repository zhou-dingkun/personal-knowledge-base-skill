# 02-资料库 — 原始材料区

> 本指令在 AI 处理本目录内容时自动加载，优先级高于根 AGENTS.md。

## 规则
1. 存放原始文件：证书、PDF、扫描件、图片等，**按主题分子目录**
2. 常见主题子目录（按需增删）：`奖项与荣誉`、`资格证书`、`学业材料`、`志愿活动`、`个人证件`、`工作材料`
3. 原始文件**只增不改**；需要更正时新建文件，不覆盖原件
4. 每个原始文件配一个同名（或同组）**.md 索引笔记**，写明：是什么 / 时间 / 来源 / 用途 / 存储路径
5. AI **优先读索引笔记**，而非直接解析二进制文件；确需解析时用 `06-Agent工具/` 中的工具
6. 含他人信息（姓名 / 学号 / 编号）或证件号的材料**仅本机使用，勿外发**（红线见根 AGENTS.md 第 6 节）
7. 新增材料后在 `INDEX.md` 的 `02-资料库` 章节登记
